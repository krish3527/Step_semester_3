## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/krish3527/Step_semester_3.git
```

### 2. Open the project

Open the cloned folder in your preferred Java IDE or editor.

### 3. Navigate to the required program

Programs are organized under:

```text
src/main/java/oops/
```

Choose either:

```text
assignment_problem
```

or

```text
practice_problem
```

### 4. Compile and run

Make sure Java is installed and configured correctly.

For example:

```bash
javac FileName.java
java FileName
```
